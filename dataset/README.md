# Dataset

## IMDb Dataset of 50K Movie Reviews

This project uses the IMDb Dataset of 50K Movie Reviews from Kaggle.

**Dataset source:**  
https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

### Dataset Information
- Total records: 50,000
- Features: Review and sentiment
- Sentiment classes: Positive and Negative
- File format: CSV

### Download Instructions
1. Visit the Kaggle dataset link above.
2. Download the dataset.
3. Extract the downloaded archive.
4. Place `IMDB Dataset.csv` in your working directory.

**Note:** The dataset is not uploaded to this repository. Please download it directly from Kaggle.
